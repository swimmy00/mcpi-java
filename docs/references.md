# 公式ドキュメント・リファレンス集

このリポジトリで使っている道具の、公式ドキュメントや参考になるページのリンク集です。
「もっと詳しく知りたい」「この命令の使い方を調べたい」ときにどうぞ。

> 英語のページも多いです。ブラウザの翻訳機能を使うと読みやすくなります。

## Python でマイクラを操作する

| リンク | 何が分かる？ |
|---|---|
| [Minecraft API リファレンス（Stuff about="code"）](https://www.stuffaboutcode.com/p/minecraft-api-reference.html) | `setBlock` や `getTilePos` など、**mcpi で使える命令の一覧**。いちばんよく使うページです |
| [mcpi（PyPI）](https://pypi.org/project/mcpi/) | このリポジトリで使っているライブラリ本体（バージョン 1.2.1） |
| [mcpi（GitHub）](https://github.com/martinohanlon/mcpi) | mcpi のソースコード |
| [Python 公式ドキュメント（日本語）](https://docs.python.org/ja/3/) | Python の文法や標準ライブラリ |

## マイクラサーバー

| リンク | 何が分かる？ |
|---|---|
| [RaspberryJuice（sakebomb 版）](https://github.com/sakebomb/RaspberryJuice) | 今使っているプラグイン。対応バージョン・使える命令・設定（`config.yml`）の説明 |
| [RaspberryJuice のリリース情報](https://github.com/sakebomb/RaspberryJuice/releases) | バージョンごとの対応状況。サーバーの `VERSION` を変える前に確認する |
| [RaspberryJuice（元祖・zhuowei 版）](https://github.com/zhuowei/RaspberryJuice) | 開発が終わった元のプロジェクト（参考） |
| [Paper](https://papermc.io/) / [Paper ドキュメント](https://docs.papermc.io/) | マイクラサーバー本体 |
| [itzg/docker-minecraft-server](https://docker-minecraft-server.readthedocs.io/) | `docker-compose.yaml` で使っている設定項目（`TYPE` `VERSION` `MODE` `PLUGINS` など）の説明 |
