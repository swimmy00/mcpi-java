# localhost とポートって何？

この環境で一番つまずきやすいのが、`localhost:4711` のような「接続先」の話です。

## ひとことで言うと

- **localhost** = 「自分のPC」という意味の特別な名前
- **ポート** = 1台のPCの中にたくさんある「窓口の番号」

`localhost:4711` は「自分のPCの、4711番の窓口」という意味です。

## たとえるなら「学校の代表電話と内線番号」

| ネットワークの用語 | たとえ |
|---|---|
| IP アドレス（`192.168.1.10` など） | 学校の代表電話番号 |
| `localhost`（`127.0.0.1`） | 「この学校の中」を指す言葉。外から電話しなくても内線で済む |
| ポート番号（`25565`、`4711`） | 内線番号。職員室、保健室、事務室…と窓口ごとに番号が決まっている |

1台のPCの中では、いくつものアプリが同時に「電話」を待っています。
どのアプリにつなぐかを決めるのがポート番号です。

この環境で使っている窓口は2つです。

| ポート | 窓口 | 誰がつなぐ |
|---|---|---|
| `25565` | マイクラサーバー本体 | マイクラ（ゲーム） |
| `4711` | RaspberryJuice | Python（mcpi） |

マイクラで `localhost` とだけ入力して接続できるのは、マイクラが「ポートを書かなければ 25565番」と決めているからです。
`mcpi` も同じように、何も書かなければ `localhost` の 4711番 につなぎに行きます。

## Docker を使うと localhost が2つになる

ここが一番ハマるところです。

[Docker って何？](docker.md) で説明したとおり、コンテナは **自分のPCの中にある別のパソコン** です。
なので、`localhost`（自分自身）も2つあります。

- **自分のPCの localhost**：Python やマイクラから見た「自分」
- **コンテナの localhost**：マイクラサーバーや RaspberryJuice から見た「自分」

学校でたとえると、**同じ敷地の中にある別の学校（コンテナ）** のようなものです。
同じ敷地にあっても、内線は別々です。

### 実際にハマった例

RaspberryJuice は、最初の設定では **「コンテナの localhost からの電話しか取らない」** ようになっています。
安全のためのデフォルト設定です。

```
Python ──▶ 自分のPC:4711 ──(Docker が転送)──▶ コンテナの入口 ✕ 受付拒否
                                               RaspberryJuice は「コンテナの中からの電話」しか取らない
```

Docker は外からの電話をちゃんとコンテナに転送しているのに、RaspberryJuice が「外線からの電話だ」と思って出てくれない状態です。

そこで、RaspberryJuice の設定（`plugins/RaspberryJuice/config.yml`）で次のように変えています。

```yaml
hostname: 0.0.0.0   # どこからの電話でも取る
```

`0.0.0.0` は「どこからでも受け付ける」という意味です。

## 「どこからでも」は危なくない？

そのままだと危ないです。
RaspberryJuice の窓口には **パスワードがありません**。つながりさえすれば、誰でもブロックを壊したり、プレイヤーを移動させたりできます。

そこで、Docker 側で **「自分のPCからの電話しか転送しない」** ように絞っています。

```yaml
# docker-compose.yml
ports:
  - "127.0.0.1:4711:4711"
#    ^^^^^^^^^ ここが「自分のPCからだけ」という意味
```

| 書き方 | 意味 |
|---|---|
| `"4711:4711"` | PC のすべての入口（Wi-Fi 経由も含む）で受け付けて、コンテナに転送する。**同じ Wi-Fi の他の人もつなげてしまう** |
| `"127.0.0.1:4711:4711"` | 自分のPCの中からだけ受け付ける。**他の端末からはつなげない** ✅ |

つまり、こういう二段構えになっています。

```
同じWi-Fiの他の端末 ──✕──▶ 自分のPC（127.0.0.1 でしか受け付けない）

自分のPCの Python  ──○──▶ 自分のPC:4711 ──▶ コンテナ:4711 ──○──▶ RaspberryJuice
                                                          （0.0.0.0 なので受け付ける）
```

- **Docker 側（`127.0.0.1`）**：PC の外からの電話はそもそも取り次がない
- **RaspberryJuice 側（`0.0.0.0`）**：Docker が取り次いだ電話は受ける

> ⚠️ この2つの設定は **必ずセットで** 扱ってください。
> `127.0.0.1` を外すと、同じネットワークにいる人から操作できてしまいます。
> マイクラ本体の 25565番 も同じ理由で `127.0.0.1` に絞っています。

## まとめ

- `localhost` は「自分のPC」、ポートは「窓口の番号」
- `localhost:4711` は「自分のPCの 4711番（RaspberryJuice）」
- Docker のコンテナは別のパソコン扱いなので、`localhost` が2つある
- RaspberryJuice は `0.0.0.0`（どこからでも）、Docker は `127.0.0.1`（自分のPCからだけ）の二段構えで、安全に接続している
