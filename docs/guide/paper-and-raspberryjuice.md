# Paper と RaspberryJuice って何？

## ひとことで言うと

- **Paper** = プラグイン（追加機能）を入れられる Minecraft サーバー
- **RaspberryJuice** = Python（mcpi）からの命令を受け付けるプラグイン

## マイクラサーバーにも種類がある

Minecraft のサーバーソフトにはいくつか種類があります。

| サーバー | 特徴 |
|---|---|
| 公式サーバー（バニラ） | Mojang 公式。追加機能は入れられない |
| **Paper** | 公式サーバーをもとに作られたサーバー。**プラグインで機能を追加できる**。動作も軽い |

Python から操作する機能は公式サーバーには無いので、プラグインを入れられる Paper を使っています。
`docker-compose.yaml` の `TYPE: "PAPER"` がその指定です。

## プラグインとは

**サーバーに後から追加する機能** です。スマホのアプリのようなものです。

マイクラの改造には「Mod」と「プラグイン」がありますが、大きな違いはここです。

| | Mod | プラグイン |
|---|---|---|
| 入れる場所 | ゲーム側とサーバー側の両方が必要なことが多い | **サーバー側だけ** |
| ゲーム側の準備 | Forge や Fabric などを入れる必要がある | **いつものマイクラのままでOK** |

プラグインはサーバー側だけで動くので、参加する人は **購入したままのマイクラで接続するだけ** で済みます。
これがこの環境でプラグインを使っている大きな理由です。

## RaspberryJuice とは

**「Minecraft: Pi Edition」の Python 操作機能を、Java版のサーバーで再現するプラグイン** です。

### 生まれた背景

- 「Minecraft: Pi Edition」は、Raspberry Pi（教育用の小さなコンピューター）向けに作られたマイクラです
- Pi Edition には、最初から Python で操作する機能（mcpi）が付いていました
- ただ、Pi Edition はもう更新されておらず、ふつうの Java版にはこの機能がありません
- そこで、同じ命令を Java版のサーバーでも受け付けられるように作られたのが RaspberryJuice です
- 今回使っているのは、最新の Paper で動くように更新された版（[sakebomb/RaspberryJuice](https://github.com/sakebomb/RaspberryJuice)）です

### やっていること

1. サーバーの中で 4711番の窓口を開いて、Python からの接続を待つ
2. `world.setBlock(10,0,5,41)` のような文字の命令を受け取る
3. その命令どおりにサーバーのワールドを変える（ブロックを置く、チャットを送る、など）
4. 必要なら返事を返す（プレイヤーの位置、ブロックの種類、など）

Python 側の `mcpi` ライブラリは、この文字の命令を作って送ったり、返事を読んだりしてくれる道具です。

### 座標は「スポーン地点が (0, 0, 0)」

この環境の RaspberryJuice は、Pi Edition に合わせて **スポーン地点を原点（0, 0, 0）とした座標** を使います（設定ファイルの `location: RELATIVE`）。
そのため、ゲーム画面の F3 キーで出る座標とは数字がずれます。

```python
pos = mc.player.getTilePos()  # スポーン地点からの相対座標が返ってくる
```

Python で座標を扱う時は、`getTilePos()` で取った位置をもとに計算するのが分かりやすいです。

## バージョンの組み合わせに注意

サーバー、プラグイン、ゲームの3つは、バージョンが合っていないと動きません。

| 組み合わせ | 合っていないと… |
|---|---|
| **ゲーム** と **サーバー** | マイクラで「互換性がありません」と出て接続できない |
| **サーバー** と **RaspberryJuice** | サーバーは起動するが、RaspberryJuice が読み込まれず Python からつながらない |

今の組み合わせはこうなっています。

| もの | バージョン |
|---|---|
| ゲーム（ランチャーの起動構成） | 26.2 |
| サーバー（Paper） | 26.2 |
| RaspberryJuice | v2.0.0（Paper 26.2 / Java 25 向け） |

### 実際にハマった例

最初はサーバーを 1.21.1 にしていましたが、ログにこう出て RaspberryJuice が読み込まれませんでした。

```
Unsupported class file major version 69
```

「major version 69」は「Java 25 用に作られたファイル」という意味です。
RaspberryJuice v2.0.0 は新しいサーバー（26.2）向けに作られていて、古いサーバー（1.21.1）では中身を読めなかったのです。
新しい Word で保存したファイルを、古い Word で開こうとしたような状態です。

> バージョンを変えたい時は、先に [RaspberryJuice のリリース情報](https://github.com/sakebomb/RaspberryJuice/releases) で対応バージョンを確認し、ゲーム側の起動構成も合わせて変えてください。

## まとめ

- **Paper** はプラグインを入れられるマイクラサーバー
- **RaspberryJuice** は Python からの命令を受け付けるプラグインで、Pi Edition の mcpi を Java版で再現している
- プラグインはサーバー側だけで動くので、ゲームはいつものマイクラのままでOK
- ゲーム・サーバー・プラグインのバージョンはそろえる必要がある
