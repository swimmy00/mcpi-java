# Docker って何？

## ひとことで言うと

**アプリを、動かすのに必要なものごと「箱」に詰めて、どのPCでも同じように動かせるようにする道具** です。

## 何がうれしいの？

マイクラサーバーを自分で動かそうとすると、ふつうはこんな準備が必要です。

1. 正しいバージョンの Java をインストールする
2. Minecraft サーバー本体をダウンロードする
3. プラグインをダウンロードして、決まったフォルダに入れる
4. 利用規約への同意ファイル（EULA）を書く
5. 設定ファイルを書く
6. 起動コマンドを打つ

しかも、PC が Mac か Windows か、すでに別のバージョンの Java が入っているか、などで手順や結果が変わってしまいます。

Docker を使うと、これが

```bash
docker compose up -d
```

の1行で終わります。そして、**誰のPCでも同じ状態で動きます。**

## たとえるなら「冷凍食品」

| Docker の用語 | たとえ | この環境では |
|---|---|---|
| **イメージ** | 冷凍食品のパッケージ。材料も調理法も全部入っている | `itzg/minecraft-server`（マイクラサーバーを動かすための一式） |
| **コンテナ** | パッケージを温めてできた一皿。実際に動いているもの | `mc-mcpi`（今動いているマイクラサーバー） |
| **docker-compose.yml** | 献立表。「どのパッケージを、どう温めて、どう盛り付けるか」を書いたメモ | このリポジトリの `docker-compose.yml` |
| **ボリューム** | 食べ残しを入れておく保存容器。お皿を洗っても中身は残る | `mc-data`（ワールドのデータ） |

- パッケージ（イメージ）が同じなら、誰が温めても同じ料理（コンテナ）ができます
- お皿（コンテナ）は気軽に捨てて作り直せます。大事なもの（ワールド）は保存容器（ボリューム）に入っているので消えません

## 「箱」の中は別世界

コンテナの中は、**自分のPCの中にあるけど、別の小さなパソコン** のように扱われます。

- コンテナの中に Java が入っていても、自分のPCに Java をインストールする必要はありません
- コンテナを消せば、中身はきれいさっぱりなくなります。自分のPCは汚れません

一方で、別のパソコンのように扱われるので、**外からつなぐには「窓口」を開けておく必要があります。**
それが `docker-compose.yml` の `ports` の設定です。

```yaml
ports:
  - "127.0.0.1:25565:25565"   # 自分のPCの25565番 → 箱の25565番（マイクラ）
  - "127.0.0.1:4711:4711"     # 自分のPCの4711番  → 箱の4711番（Python用）
```

> この「窓口」の話は [localhost とポートって何？](localhost-and-ports.md) で詳しく解説しています。

## Docker Desktop とは

Docker を Mac や Windows で使うためのアプリです。

- **Docker Desktop が起動している間だけ**、コンテナは動きます
- PC を再起動したら、Docker Desktop も起動してください
- 画面の「Containers」から、動いているコンテナ（`mc-mcpi`）の様子を見ることもできます

## よく使うコマンド

このフォルダの中で実行します。

| コマンド | 意味 | たとえ |
|---|---|---|
| `docker compose up -d` | 起動する（なければ作る） | 献立表どおりに料理を出す |
| `docker compose down` | 止めて片付ける（ワールドは残る） | お皿を下げる（保存容器は残す） |
| `docker compose down -v` | 止めて、ワールドも消す | 保存容器ごと捨てる ⚠️ |
| `docker compose logs -f` | 動いている様子を見る | 厨房をのぞく |
| `docker compose ps` | 動いているか確認する | 料理が出ているか確認する |

`-d` は「裏で動かしておいて」という意味です。付けないとターミナルがサーバーのログ表示で埋まってしまいます。

## まとめ

- Docker は、アプリを必要なものごと「箱」に詰めて動かす道具
- おかげで、マイクラサーバーの面倒な準備が `docker compose up -d` の1行で済み、誰のPCでも同じように動く
- 箱の中は別のパソコン扱いなので、外からつなぐには `ports` で窓口を開ける
